# 第一课静态 HTML 课程实施计划

**目标：** 将现有《化学入门教程.md》完整转为第一课，原十讲在页面中称为十个小节，保留全部正文、观察、自测、延伸阅读及参考链接。

**架构：** 本地 Python 构建脚本读取原 Markdown，生成语义化正文；本地模板、CSS 和原生 JavaScript 全部内联进单个 `lesson-01.html`。浏览器不需要编译器、网络服务或外部资源，关闭 JavaScript 也能阅读正文。

**技术栈：** Python 标准库与本机已有的 Markdown 3.10.3（仅用于构建，不需安装）、HTML5、CSS、原生 JavaScript、原生 SVG；Chrome DevTools MCP 验证。交付 HTML 无第三方运行依赖。

## 设计与取舍

- 采用书籍式连续阅读而不是幻灯片分页或强制闯关，适合成人从基础开始学习。
- 暖白纸色、深森林绿、陶土红重点色；宋体风格标题配清晰黑体正文，字体采用本地可用字体且不复制商业字体文件。
- 桌面固定课程目录，移动端折叠目录；正文 18 px 起，限制行宽，清晰焦点和减弱动画支持。
- 补充水分子、三态、守恒与能量示意，说明示意图不是比例模型；不使用装饰性的错误科学模型。
- 每小节有手动完成状态，目录定位、字号调节、自测展开、打印；本地存储异常时仍可阅读操作。
- 自测使用原有五道问题，默认折叠解析，不把滚动当成学会。
- 不上传外网、不安装依赖、不创建可见终端、不自动打印。

## 实施步骤

1. 创建 `tests/test_course.py`，验证十个小节、原文覆盖、来源链接、唯一锚点和离线资源约束；先运行以确认缺失页面时失败。
2. 创建 `tools/build_course.py` 与 `src/lesson-01.template.html`，解析当前 Markdown 用到的标题、段落、列表、表格、引用、链接和强调，不修改源文档。
3. 创建 `src/course.css` 与 `src/course.js`，实现响应式布局、导航和完成状态、字号、打印；构建 `lesson-01.html`。
4. 运行自动测试和 JavaScript 语法检查，修复问题。
5. 创建本任务预览服务 `tools/preview.py`，仅监听 `127.0.0.1`，绑定随机空闲端口，严格路由白名单，无目录浏览，记录 PID、端口、工作目录及日志。
6. 使用已发现的 Chrome DevTools MCP，在本任务专属隔离上下文打开页面，读取快照并截图视觉检查；测试桌面、窄屏、字体放大、导航、自测、进度持久化、打印和关闭 JavaScript 的可读性。
7. 交付单文件 HTML 的本地路径，说明附加功能及真实验证范围。

## 验收标准

- 十小节与后续内容完整，源文档不变，十五个来源链接保留。
- 无外部脚本、样式、字体或图片请求；原生 SVG 可访问，颜色不是唯一提示。
- 320 px / 390 px / 桌面宽度无整页横向溢出；键盘可导航。
- 完成状态仅由用户主动标记；本地存储失败不会使功能崩溃。
- 打印显示完整正文与自测答案，隐藏导航和操作控件。
- 仅管理本任务页面和进程，不接管其他浏览器页面。
